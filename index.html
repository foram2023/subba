Rohan Subba

PhD researcher focused on reconstructing past ocean oxygenation using benthic foraminifera and machine learning based morphometrics. I develop computational tools and field-based proxies to study low-oxygen events and palaeoenvironmental change.

Download CV See Publications

Research overview

My work combines laboratory culture experiments, morphometric analysis, and machine learning to develop proxies for past oxygenation. I build open-source tools (Python, OpenCV, PySide6) for image analysis and morphometry.

Selected projects

MicroPerspective — automated pore detection and morphometric analysis for foraminifera.
Python, OpenCV, PySide6
Oxygenation proxies — multi-proxy modelling of low-oxygen events from benthic foraminiferal assemblages.
Field sampling • Lab experiments • Statistical modelling
